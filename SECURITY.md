# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues. Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. If that is not possible, e-mail developericaruz@gmail.com instead.

Include the affected version, steps to reproduce and the impact. You will get a response as soon as the maintainer can, and a fix is released before details are made public.
